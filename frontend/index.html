Shrinkflation Sleuth is a Gemini agent that looks up a product's documented size changes and works out how much more you now pay per ounce. Each size cut links to the report it came from.

Shrinkflation

Price per unit is the sticker price divided by the size. At $4.99, 9.75 oz works out to $0.51 an ounce. At 9.25 oz the same $4.99 is $0.54 an ounce. That change in price per ounce is the hidden increase.

This is one example from 29 documented size cuts in the demo data, not a typical result. The average across those cuts is in the figures below.

What the data shows

Run the agent's playbooks yourself

The real agent uses Gemini to plan Elasticsearch queries. This explorer runs the same playbooks deterministically in your browser over the exact documents the agent queries, so no API key is needed. Each result shows the tool calls the agent makes for it.

Demo data: 34 products curated from public shrinkflation reports (FullCarts, Mouseprint, ShrinkWatch, Capital One Shopping research). Sizes and dates follow the reports; prices are representative, not live quotes. Reddit-only reports are marked unverified. Methodology.

Questions the full agent handles

With the full agent you ask in plain English and Gemini picks the playbook.

  • Has my Doritos bag gotten smaller?

    Product lookup: size history, price-per-unit trend, verdict.

  • Show me all shrinkflation from Frito-Lay

    Brand investigation: products ranked by shrinkage, via an ES|QL aggregation.

  • Which category has the worst shrinkflation?

    Category analysis: average shrinkage per category and the worst three products.

  • Check these: Doritos, Charmin, Tide, Oreos

    Shopping list audit: each item checked, plus the total hidden cost.

  • What are the worst trends this year?

    Trend dashboard: the ten biggest cuts and a count per year.

  • What data do you have?

    Data discovery: lists the indices and reads their mappings.

One Gemini agent, five read-only MCP tools

Built with Gemini Flash on Google ADK, connected to Elasticsearch through the official Elastic MCP server. A product question takes three tool calls: search for the product, pull its history with ES|QL, then look up the documented size change.

USER ──► GEMINI FLASH (ADK agent)
              │ plans steps, picks tools
              ▼
      ELASTIC MCP SERVER
      ├─ search          find the product
      ├─ esql            price-per-unit analytics
      ├─ list_indices    discover data
      ├─ get_mappings    understand schema
      └─ get_shards      shard status
              │
              ▼
      ELASTICSEARCH  (products · product_history · shrinkflation_alerts · categories)

Running the full agent needs an Elasticsearch cluster and a Gemini key; see the quickstart.
