How it works

Gemini plans. Elasticsearch answers.

Built with Gemini Flash on Google ADK, connected to Elasticsearch through the official Elastic MCP server. Every answer is a multi-step mission: discover the data, search the catalog, run ES|QL analytics, cross-check verified alerts, then report.

USER ──► GEMINI FLASH (ADK agent) │ plans steps, picks tools ▼ ELASTIC MCP SERVER ├─ search find the product ├─ esql price-per-unit analytics ├─ list_indices discover data ├─ get_mappings understand schema └─ get_shards verify data health │ ▼ ELASTICSEARCH (products · product_history · shrinkflation_alerts · categories)

Running the full agent needs an Elasticsearch cluster and a Gemini key; see the quickstart.
